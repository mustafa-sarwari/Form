# Contributing to Form Project

Thank you for your interest in contributing to the Form project! 🎉

## How to Contribute

### Reporting Bugs

If you find a bug, please open an issue with:
- A clear description of the problem
- Steps to reproduce the issue
- Expected vs. actual behavior
- Screenshots (if applicable)
- Your browser and operating system information

### Suggesting Enhancements

We welcome suggestions for improvements! Please open an issue with:
- A clear description of the enhancement
- Why this would be useful
- Any examples or mockups (if applicable)

### Pull Requests

1. **Fork the repository** and create your branch from `main`
2. **Make your changes** with clear, descriptive commit messages
3. **Test your changes** thoroughly in multiple browsers
4. **Update documentation** if you've changed functionality
5. **Submit a pull request** with a clear description of your changes

### Code Style Guidelines

- Use consistent indentation (2 spaces)
- Write semantic HTML with proper accessibility attributes
- Keep CSS organized and well-commented
- Use meaningful variable and function names in JavaScript
- Follow modern JavaScript best practices (ES6+)
- Test responsiveness across different screen sizes

### Commit Message Format

Use clear, descriptive commit messages:
```
Add feature: Brief description of what you added
Fix bug: Brief description of what you fixed
Update: Brief description of what you updated
```

## Development Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/mustafa-sarwari/Form.git
   cd Form
   ```

2. Open `index.html` in your browser or use a local server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx http-server
   ```

3. Make your changes and test in multiple browsers

This project adheres to a [Code of Conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code.
