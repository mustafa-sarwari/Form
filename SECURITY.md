# Security Policy

## Supported Versions

This project is a frontend-only application with no backend dependencies. The latest version on the `main` branch is always supported.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it by:

1. **DO NOT** open a public issue
2. Contact the maintainer via GitHub issues (mark as security issue) or email
3. Include:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

We will respond within 48 hours and work to address the issue promptly.

## Security Best Practices

This project implements:
- HTML5 form validation
- Client-side input sanitization
- No sensitive data storage
- No external API calls
- Secure content delivery via HTTPS (on GitHub Pages)

## Responsible Disclosure

We appreciate responsible disclosure of security vulnerabilities. We will:
- Acknowledge receipt of your report within 48 hours
- Keep you informed of our progress
- Credit you in the fix (unless you prefer to remain anonymous)

Thank you for helping keep this project secure! 🔒
